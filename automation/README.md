# Automation

This directory documents how the repository is expected to evolve over time.

## Intended ongoing loops

- daily or periodic public-source case capture
- weekly digest generation
- ability upgrades after repeated evidence
- sync-contract refinement when Notion structure changes

## Rules

- local repository files are the versioned source of truth
- Notion is an operational mirror, not the only durable store
- scheduled updates must remain reviewable
- no workflow should claim success without validation
