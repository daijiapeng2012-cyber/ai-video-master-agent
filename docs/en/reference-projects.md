# Reference Projects

This repository takes inspiration from several strong open-source patterns:

## 1. ComfyUI

Why it matters:

- clear project positioning
- strong README-driven onboarding
- visible open-source community expectations

What we borrow:

- explicit scope
- scriptable workflow entry points
- community-friendly repository layout

## 2. Flowise

Why it matters:

- productized AI workflow repository with accessible docs
- strong GitHub-facing project presentation

What we borrow:

- readable repository framing
- clear separation between docs, source structure, and user-facing explanation

## 3. LangChain

Why it matters:

- mature open-source AI ecosystem project
- strong repo hygiene, docs, and contributor expectations

What we borrow:

- community-health completeness
- strong contribution and repository conventions
- documentation-first credibility

## 4. GitHub community health standards

Why it matters:

- the fastest way to make a repository feel real, trustworthy, and maintainable

What we borrow:

- LICENSE
- CONTRIBUTING
- CODE_OF_CONDUCT
- SECURITY
- issue templates
- pull request template
- validation CI

## Our difference

Unlike general AI agent repos, this project is specialized around:

- AI video workflow knowledge
- ability extraction from public cases
- weekly digest publishing
- a clean split between knowledge and execution layers
