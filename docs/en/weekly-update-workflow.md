# Weekly Update Workflow

## Goal

Turn ongoing AI video scanning into a clean weekly GitHub update.

## Cadence

### During the week

- add public cases
- refine or link abilities
- keep evidence boundaries explicit

### End of week

- validate the knowledge base
- generate the weekly digest
- review the digest
- commit and publish

## Weekly digest structure

1. new or important cases
2. new or refined abilities
3. recurring method patterns
4. evidence boundaries

## Rules

- do not invent items to hit a quota
- prefer high-signal public material over breadth
- keep changelog-type items labeled as parameter evidence
- only mark an ability solid when it is reusable across more than one narrow event
