# 架构说明

## 一句话

AI 视频大师Agent = `案例雷达` + `知识库` + `技能层` + `执行层接口`

## 四层结构

### 1. 雷达层

输入：

- 官方教程
- 官方 changelog
- 公开工作流文章
- 可复现案例

输出：

- 结构化案例
- 证据边界
- 候选可复用模式

### 2. 知识层

输入：

- 经过筛选的高价值案例

输出：

- 能力
- 类别
- 阶段
- 模板

### 3. 技能层

输入：

- 用户目标
- 当前知识库
- 仓库规则

输出：

- 路由决策
- 能力升级判断
- 执行层 handoff 策略

### 4. 执行层接口

本仓库不直接渲染媒体。

它负责向 `ai-video-supervisor` 这类执行层提供稳定知识，让后者管理
prompt、manifest、review 状态和真实项目执行。

## 设计原则

1. 公开证据优先。
2. 案例不等于能力。
3. Notion 不是唯一真相源。
4. 执行层必须和知识层分离。
5. changelog 可以证明参数约束，但不能自动证明视觉质量。
