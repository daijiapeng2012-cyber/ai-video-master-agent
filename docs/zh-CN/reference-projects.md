# 参考项目

这个仓库的结构和标准，参考了几类成熟开源项目的做法。

## 1. ComfyUI

参考原因：

- 项目定位清楚
- README 驱动的 onboarding 很强
- 开源社区感明显

借鉴点：

- 明确 scope
- 清晰入口
- 适合社区阅读的结构

## 2. Flowise

参考原因：

- AI 工作流项目的产品化表达比较完整
- GitHub 展示方式成熟

借鉴点：

- 仓库叙事清楚
- 文档和结构分层明确

## 3. LangChain

参考原因：

- 成熟 AI 开源生态项目
- 仓库治理、文档、贡献规范完整

借鉴点：

- 社区健康文件齐全
- 贡献规范明确
- 文档优先，增强可信度

## 4. GitHub 社区健康标准

参考原因：

- 这是让仓库“看起来像真的长期项目”最快的方法

借鉴点：

- LICENSE
- CONTRIBUTING
- CODE_OF_CONDUCT
- SECURITY
- issue templates
- pull request template
- CI 校验

## 本项目的差异

和通用 AI Agent 仓库不同，这个项目更聚焦：

- AI 视频工作流知识
- 从公开案例中抽能力
- 持续输出周报
- 把知识层和执行层明确分离
