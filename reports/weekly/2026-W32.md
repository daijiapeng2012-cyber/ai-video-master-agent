## 能力沉淀

### 干净底板负面清单 (`clean_plate_negative_pack`)

- 类别：质检与返工
- 状态：solidified
- 适用阶段：Storyboard, Review, Delivery
- 定义：需要移除人和阴影时，先定义 clean plate 目标和禁止残留物，再做修补或扩展。
- 模板：clean plate target + forbidden artifacts + patch region + continuity check

### 人群密度与机位先行 (`crowd_density_framing_prompt`)

- 类别：分镜与节拍
- 状态：solidified
- 适用阶段：Storyboard, Higgsfield, Review
- 定义：先定义人群密度、层次和机位，再写背景角色行为，避免 crowd shot 只靠风格词漂移。
- 模板：crowd density + camera placement + extras behavior + action priority

### 对白节拍分段提示 (`dialogue_beat_segmentation`)

- 类别：表演与口型
- 状态：solidified
- 适用阶段：Script, Storyboard, Higgsfield, Review
- 定义：对白和表演不要整段交给模型，先按停顿、情绪、动作转折拆成 beat 再提示。
- 模板：line intent + pause + emotional turn + gesture cue + end state

### 领域词汇提示法 (`domain_vocabulary_prompting`)

- 类别：执行与编排
- 状态：solidified
- 适用阶段：Storyboard, Higgsfield
- 定义：优先使用行业内的场景词汇和工种词，而不是泛化形容词，提升模型对专业镜头与材质的响应。
- 模板：domain-specific nouns + production context + action constraint

### 动作-材质 Foley 提示 (`foley_action_material_prompt`)

- 类别：音频驱动
- 状态：solidified
- 适用阶段：Storyboard, Higgsfield, Delivery
- 定义：先把动作和接触材质成对绑定，再补 Foley 层，而不是只写抽象音效氛围。
- 模板：action + contact material + sound texture + timing

### 光向球单次重打光 (`light_direction_ball_relight`)

- 类别：交付与后期
- 状态：solidified
- 适用阶段：Keyframe, Review, Delivery
- 定义：先锁主光方向和受光体逻辑，再做一次性重打光，避免多轮 relight 让材质和空间关系失真。
- 模板：light direction + subject response + environment consistency + final pass

### LoRA 训练决策闸门 (`lora_training_decision_gate`)

- 类别：模型路由
- 状态：solidified
- 适用阶段：Producer, Worldbuilding, Keyframe
- 定义：先判断角色/风格问题能否靠 reference 和控制词解决，再决定是否值得训练 LoRA。
- 模板：reuse refs -> test base model -> compare drift cost -> decide LoRA or not

### 控件先于提示词 (`selector_before_prompt_lock`)

- 类别：执行与编排
- 状态：solidified
- 适用阶段：Producer, Storyboard, Keyframe, Higgsfield, Review
- 定义：先用 references 与 selector 锁时代、镜头、光线和物理规则，再让 prompt 只描述动作与事件。
- 模板：references -> selectors -> action prompt -> local correction

### 尺寸参照锁尺图 (`size_ref_scale_lock`)

- 类别：控制资产
- 状态：solidified
- 适用阶段：Storyboard, Keyframe, Higgsfield
- 定义：通过尺寸参照和比例锚点，把物体、人和空间尺度先锁死，再做运动和光影变化。
- 模板：scale anchor + size reference + environment relation + movement goal

### 声音锚点配置锁 (`voice_anchor_config_lock`)

- 类别：音频驱动
- 状态：solidified
- 适用阶段：Producer, Higgsfield, Review, Delivery
- 定义：同一角色或旁白先锁唯一 voice source 与完整声音配置，再让所有后续片段只复用该配置。
- 模板：single voice source + saved config + repeat reuse + explicit versioning
